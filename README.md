# NextTask PWA v2

カードを選ぶほど候補順位が変わる学習型タスクアプリです。

## 主な機能
- 上位3件のカード表示
- 「これをやる」→ 実行中 → 完了 / スキップ
- 「あとで」の学習
- 完了率の学習
- 直前タスクから次に選ぶ流れの学習
- 平日/休日 × 朝/昼/夕方/夜/深夜の文脈学習
- 優先度
- localStorage保存
- JSON書き出し
- PWA対応 / オフラインキャッシュ

## 重要
ChatGPT内のHTMLプレビューではJavaScriptが動かない場合があります。
実際に使うには、このフォルダをGitHub Pages / Netlify / Vercelなどの静的ホスティングに置いてください。
