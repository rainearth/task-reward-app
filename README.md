# NextTask PWA v3

カードを選ぶほど候補順位が変わる学習型タスクアプリです。

## v3
- 起床 / 就寝を1日のサイクル境界として固定
- 就寝で行動履歴を切断
- 起床から新しい行動列を開始
- 最大3個前までを見る可変N-gram
  - 2-gram: 直前1行動
  - 3-gram: 直前2行動
  - 4-gram: 直前3行動
- データが少ないときは短いN-gramへ自動バックオフ
- 実際に観測した並びだけ保存する疎な辞書方式
- 平日/休日 × 時間帯、完了率、優先度、後回しも併用

## 軽量性
推論時に見る履歴は最大3行動だけです。
1つの完了につき最大3つのN-gramカウントを更新するだけなので、端末負荷は小さい設計です。

## 保存
データは端末ブラウザの localStorage に保存されます。


## v4: 時間減衰
- N-gram の観測値は30日を半減期とする指数減衰
- 完了率・時間帯適性は古くなるほど中立値へ戻る
- スキップ / 後回しのペナルティも時間とともに弱くなる
- 古い生活習慣を残しつつ、最近の行動へ追従しやすくした
